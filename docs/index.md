# FlowDesk

**Your personal knowledge memory system.**

FlowDesk is a full-stack personal knowledge and productivity hub — bookmarks,
markdown notes, code snippets, routine, expenses, files, and an AI assistant,
behind a single login and hosted entirely on Cloudflare.

![FlowDesk](assets/og-image.png)

## Highlights

- **Everything in one vault** — 10+ modules, one search bar, one login.
- **230+ chapters of developer docs** — DSA, Rust, Python, ML, and more, built in.
- **AI that acts** — the assistant doesn't just chat; it can create bookmarks,
  notes, and routines for you.
- **Edge-native** — Cloudflare Pages Functions + D1 + R2. No servers to manage.
- **Android app** — Capacitor shell with local notifications, released automatically
  via GitHub Actions.
