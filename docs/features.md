# Features

## Bookmarks

Save links with automatic title/description extraction, category filters, favorites,
and duplicate-URL warnings. Every bookmark can be shared through an unguessable
public link.

## Notebooks

Markdown editor with live preview, AI-powered text processing, draft auto-save,
and note history. Notes support callouts, math (KaTeX), and code highlighting.

## Code Book

Reusable snippets with syntax highlighting, language auto-detection, fuzzy search,
and favorites. Snippets can be explained by AI in plain language.

## Questions

A tracker for competitive-programming and interview problems with tags, difficulty
levels, and metadata fetching from problem URLs.

## Routine

Daily schedule with hour blocks, statuses, and a scratchpad. Reminders run as
**local Android notifications** — no server push needed — and any routine exports
to a standard `.ics` calendar file.

## Hisab

Expense and budget tracker: interactive charts, inline editing, transfers between
accounts, and AI-powered financial planning prompts.

## Progress

Roadmap management (import/export as JSON), daily habit check-ins, and a rolling
consistency chart. Drag-and-drop reordering everywhere.

## Passwords

Password manager with categories and search plus a **TOTP authenticator** — 2FA
codes generated locally with WebCrypto. Secrets never leave the device unencrypted
over the API.

## Files

Upload up to 300 MB via multipart, stream video through a JW Player wrapper with
R2 Range requests, and share any file via public link.

## AI Chat

A multi-provider assistant (Gemini / OpenAI / OpenRouter) with message history,
file attachments, and *actions*: it can create bookmarks, notes, routines, and
other resources directly from the conversation.

## Docs

230+ chapters of developer documentation across 23 categories — DSA with
interactive visualizations, Rust, Python, Transformers, FastAPI, Redis, Docker,
English for developers — in Bengali with English translations for selected
categories. Public reading; notes, progress, and search require login.
