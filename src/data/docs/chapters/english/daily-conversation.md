# Daily Conversation — প্রতিদিনের কথা বলার ইংরেজি

তুমি হয়তো ইংরেজি পড়তে পারো, লিখতে পারো — কিন্তু কথা বলার সময় মাথা খালি হয়ে যায়! এটা সবার সাথে হয়। কারণ আমরা বইয়ের ইংরেজি শিখি, কিন্তু মানুষ যেভাবে কথা বলে সেটা আলাদা।

এই চ্যাপ্টারে আমরা ১০০+ এরো দৈনন্দিন বাক্য শিখবো — ঠিক যেভাবে বন্ধুদের সাথে, সহকর্মীদের সাথে, বা দোকানদারের সাথে কথা বলতে হয়। প্রতিটা ক্যাটাগরি আলাদা, তাই তুমি যখন যা দরকার, সেটা সরাসরি পড়ে নিতে পারবে।

> [!tip] কীভাবে পড়বে
> প্রতিটা বাক্য মুখে বলো, শুধু চোখে পড়লে হবে না। ইংরেজি শেখার সবচেয়ে বড় ভুল হলো — শুধু পড়া, না বলা। আজ থেকেই শুরু করো, একটা একটা করে মুখে বলো।

## 1. Greeting ও Small Talk

দিনের শুরুতে কাউকে দেখলে কী বলবে? "Good morning, how are you?" — এটা ঠিক আছে, কিন্তু একটু পুরোনো ধাঁচের। আজকাল মানুষ সহজ ভাষায় কথা বলে। চলো দেখি।

| বাংলা | English | Note |
|--------|---------|------|
| কি খবর? | What's up? | বন্ধুদের সাথে সবচেয়ে common |
| কেমন আছো? | How are you? | Formal, যেকোনো জায়গায় চলবে |
| কেমন চলছে? | How's it going? | What's up এর মতোই, একটু নরমাল |
| অনেকদিন দেখা নেই! | Long time no see! | পরে দেখা হলে বলো |
| কোথায় ছিলে? | Where have you been? | কাউকে অনেকদিন পর দেখলে |
| সব ঠিক আছে? | Everything okay? | কেউ চুপ থাকলে বা দুশ্চিন্তাগ্রস্ত দেখালে |
| কি গতি হাল? | What's going on? | কিছু একটা হচ্ছে দেখলে |
| সাম্প্রতিক অবস্থা কি? | What's new? | পুরোনো বন্ধু হঠাৎ দেখা হলে |
| ভালো তো? | You good? | খুব informally, বন্ধুকে জিজ্ঞেস করার মতো |
| চলছে চলছে | I'm doing okay / Not bad | এটা সবচেয়ে নিরাপদ reply |

> [!tip] What's up এর reply কী দেবে?
> সবচেয়ে সহজ reply হলো — "Nothing much, you?" মানে "বিশেষ কিছু না, তোমার খবর কি?" এটাই সবচেয়ে common।

```
Arafat: Hey! What's up?
Sadia:  Nothing much. You?
Arafat: Just chilling. Coffee খাবে?
Sadia:  Sure, চলো!
```

```
Rakib:  Long time no see! কোথায় ছিলে?
Nila:   আমি তো গ্রামে ছিলাম, বাড়িতে।
Rakib:  আহ! How was it?
Nila:   দারুণ! অনেক ঘুরেছি।
```

## 2. প্রশ্ন করা

মাঝে মাঝে খুব simple প্রশ্নও মনে পড়ে না। চলো সেগুলো একসাথে দেখি।

| বাংলা | English | Note |
|--------|---------|------|
| কি করছো? | What are you doing? | WhatsApp এ সবচেয়ে বেশি লেখা হয় |
| কোথায় যাচ্ছো? | Where are you going? | কেউ তাড়াতাড়ি বের হলে |
| কি ভাবছো? | What are you thinking? | কেউ চুপ করে আছে দেখলে |
| কেমন চলছে? | How's it going? | কাজের খবর নেওয়ার সহজ উপায় |
| কি হলো? | What happened? | কিছু একটা শুনলে বা দেখলে |
| কেন তাই? | Why is that? | কেউ কিছু বললে, reason জানতে |
| কে বললো? | Who told you? | খবর পেলে বা gossip হলে |
| কখন যাবে? | When are you going? | Schedule জানতে |
| কী কারণে? | What for? | "কেন?" এর informal ভার্সন |
| তারপর? | And then? | গল্পের মাঝে রুচি রাখতে |

```
Mim:   What are you doing?
Hasan: তেমন কিছু না, ইউটিউব দেখছি।
Mim:   কি দেখছো?
Hasan: একটা coding tutorial।
```

> [!note] What বনাম How
> "What are you doing?" মানে "কি করছো?" — কাজ জানতে চাওয়া। "How are you doing?" মানে "কেমন আছো?" — অবস্থা জানতে চাওয়া। এই পার্থক্যটা মাথায় রাখবে।

## 3. Feelings প্রকাশ করা

ভাবনা, আনন্দ, দুঃখ — সব প্রকাশ করতে হয়। বন্ধুদের সাথে এগুলো সবচেয়ে বেশি দরকার।

| বাংলা | English | Note |
|--------|---------|------|
| ভালো লাগছে না | I don't feel good | Physical বা mood — দুটোর জন্যেই চলে |
| খুব ভালো লাগছে | I'm really enjoying it | কিছু ভালো লাগলে |
| বিরক্ত লাগছে | It's annoying / That's frustrating | কিছু বারবার হলে |
| ভয় লাগছে | I'm scared / That's scary | সিনেমা, খবর, বা situation |
| অবাক লাগছে | I'm surprised / That's surprising | অপ্রত্যাশিত কিছু হলে |
| দুঃখিত | I'm sorry / I'm sad | "I'm sorry" = ক্ষমা চাওয়া, "I'm sad" = মন খারাপ |
| খুশি হলাম | I'm happy / I'm glad | ভালো খবর শুনলে |
| থাকতে পারি না | I can't wait | উত্তেজনা প্রকাশ করতে |
| ক্লান্ত লাগছে | I'm exhausted | দিন শেষে বা কাজ শেষে |
| রাগ লাগছে | I'm angry / I'm mad | মার্কিন ইংরেজিতে "mad" = রাগ |

```
Tania: কেমন লাগছে movie?
Sajid: I'm really enjoying it! দারুণ আছে।
Tania: আমারও। Wait, এই দৃশ্যটা ভয়ের!
Sajid: Yeah, that's scary!
```

> [!tip] "I'm sorry" vs "I'm sad"
> এটা প্রায়ই confuse হয়। "I'm sorry" মানে "আমি দুঃখিত" — ক্ষমা চাওয়ার সময় বলো। আর "I'm sad" মানে সত্যিই মন খারাপ। মনে রাখবে — sorry দিয়ে ক্ষমাও চাওয়া যায়, সহানুভূতিও প্রকাশ করা যায়।

## 4. Plans ও Decisions

কি করবে, কখন করবে — সবকিছুর plan বানাতে হয়। এই বাক্যগুলো রোজ দরকার হয়।

| বাংলা | English | Note |
|--------|---------|------|
| আজকে যাবো না ভার্সিটি | I won't go to university today | মন নেই, আজ rest নেওয়া দরকার |
| কালক করবো | I'll do it tomorrow | আজ না করলে কালক |
| ঠিক আছে | Okay / Sure / Alright | সবচেয়ে common response |
| চলো যাই | Let's go | দুজনে বা গ্রুপে |
| পরে দেখি | I'll see later / I'll check later | এখন না ভাবলে |
| ভাবতে দাও | Let me think | সময় দরকার |
| ঠিক করেছি | I've decided | সিদ্ধান্ত নেওয়া হয়ে গেছে |
| চেষ্টা করবো | I'll try | কথা দিচ্ছি না, চেষ্টা করবো |
| নিশ্চিত না | I'm not sure | সন্দেহ আছে |
| কি পরিকল্পনা? | What's the plan? | কিছু ঠিক করতে হলে |

```
Imran: কালক কি প্ল্যান? বেরোবে?
Faria: I'm not sure. তুমি কি বলছো?
Imran: চলো না movie দেখি!
Faria: Okay, চলো! কোন হলে?
Imran: Let me think, আজকে সিদ্ধান্ত নিই।
```

> [!example] Common Pattern
> "I'll + verb" দিয়ে future বোঝায় — "I'll go", "I'll call", "I'll check"। এটা রোজ দশটা বার ব্যবহার হয়।

## 5. খাওয়া ও খিদে

খাওয়া নিয়ে কথা বলা — এটা এড়িয়ে যাওয়ার উপায় নেই! মানুষের জীবনে সবচেয়ে common topic।

| বাংলা | English | Note |
|--------|---------|------|
| খেয়েছো? | Have you eaten? | বাঙালির "কেমন আছো" এর সমতুল্য |
| খিদে লেগেছে | I'm hungry | সবচেয়ে simple কথা |
| কি খাবে? | What will you eat? / What do you want? | রেস্টুরেন্টে বা বাসায় |
| জল খাবে? | Want some water? | অতিথি এলে |
| দারুণ স্বাদ | It tastes great / It's delicious | মুগ্ধ হলে |
| এটা মজার না | This doesn't taste good | ভালো না লাগলে নরমাল ভাবে |
| আর খাওয়ার জায়গা নেই | I'm full / I can't eat anymore | পেট ভরে গেলে |
| খিদে মরে যাচ্ছে | I'm starving | খুব বেশি খিদে লাগলে |
| চা খাবে? | Want some tea? | বাঙালির চা চাওয়া |
| অর্ডার দেওয়া যাক? | Shall we order? | রেস্টুরেন্টে |

```
Waiter: What would you like to order?
Rana:  একটা biryani দিন।
Rina:  আমার জন্য beef curry।
Waiter: Anything to drink?
Rana:  দুটো Coke।
```

> [!tip] "Starving" এর সত্যিকারের অর্থ
> "I'm starving" মানে সত্যিই না খেয়ে মরে যাচ্ছো — অবশ্যই এটা আক্ষরিক অর্থে নয়। এটা খুব common exaggeration। আমরা বাংলায় বলি "খিদে মরে যাচ্ছে" — same vibe।

## 6. সময় ও Schedule

সময় মানেই জীবন। কখন কোথায় যেতে হবে — এই বাক্যগুলো সবচেয়ে বেশি দরকার।

| বাংলা | English | Note |
|--------|---------|------|
| কয়টায় যাবে? | What time will you go? | Schedule জানতে |
| কতক্ষণ লাগবে? | How long will it take? | কাজের সময় জানতে |
| দেরি হয়ে গেছে | It's late / I'm running late | দৌড়ে যেতে হবে |
| এখনি যেতে হবে | I need to go now / I gotta go | তাড়াতাড়ি দরকার |
| সময় হয়ে গেছে | Time's up / It's time | সময় শেষ |
| কটায় meeting? | What time is the meeting? | অফিসে বা ভার্সিটিতে |
| পাঁচ মিনিট দাও | Give me five minutes | সামান্য সময় দরকার |
| আজকেই শেষ করবো | I'll finish it today | deadline আছে |
| এখনও সময় আছে | There's still time | তাড়া নেই |
| সময় মতো | On time / Punctually | ঠিক সময়ে |

```
Sajid: কয়টায় class?
Nila:  দশটায়। কিন্তু I'm running late!
Sajid: কতক্ষণ লাগবে?
Nila:  আরও পনেরো মিনিট।
Sajid: ঠিক আছে, তাড়াতাড়ি এসো।
```

> [!note] "Gotta" হলো "have got to" এর short form
> "I gotta go" মানে "আমাকে এখনি যেতে হবে"। এটা informal কিন্তু রোজ ব্যবহার হয়। Formal জায়গায় "I need to go" বা "I must go" বলো।

## 7. কাজ ও পড়া

ভার্সিটি, চাকরি, assignment — সব নিয়ে কথা বলা। এই বাক্যগুলো student আর professional সবার দরকার।

| বাংলা | English | Note |
|--------|---------|------|
| কাজ শেষ? | Is work done? / Are you done? | progress জানতে |
| পড়া হয়েছে? | Have you studied? | exam আসলে সবচেয়ে common |
| খুব ব্যস্ত | I'm very busy / I'm swamped | কাজে ডুবে আছো |
| কাজ আছে | I have work to do | সময় নেই |
| আজকে off নেবো | I'll take a day off today | বিশ্রাম দরকার |
| assignment বাকি | I have an assignment due | deadline চাপছে |
| প্রেজেন্টেশন আছে | I have a presentation | stage ভয় করে |
| কাজ চলছে | It's in progress / I'm working on it | হচ্ছে, শেষ হয়নি |
| submit করেছো? | Have you submitted? | deadline বুঝতে |
| বিরতি নেওয়া দরকার | I need a break | ক্লান্ত হলে |

```
Sumi:  Assignment শেষ?
Rana:  না, I'm working on it। আরও দুঘণ্টা লাগবে।
Sumi:  তাড়া নেই, আমিও বাকি।
Rana:  Good। চলো একসাথে করি।
```

> [!tip] "Swamped" — একটা দরকারি word
> "I'm swamped" মানে "আমি কাজে ডুবে আছো" — খুব বেশি ব্যস্ত। "busy" এর চেয়েও strong শব্দ। Office এ খুব কাজে লাগে।

## 8. Phone ও Chat

ফোনে কথা বলা আর চ্যাট করা — এই দুটো আলাদা। চ্যাটে ছোট ছোট বাক্য চলে, ফোনে পুরো বাক্য লাগে।

| বাংলা | English | Note |
|--------|---------|------|
| কল করছিলাম | I was calling you / I tried calling you | কল ধরল না |
| মেসেজ দিয়েছিলাম | I messaged you / I texted you | reply পাওনি |
| রিপ্লাই দাওনি | You didn't reply | একটু complain |
| কল ব্যাক করো | Call me back | ফোন রাখার আগে |
| একটু পরে কথা বলি | I'll call you back | এখন সময় নেই |
| কি করছো? | What are you up to? | chat এ খুব common |
| অনলাইন ছিলে না | You weren't online | reply দেরিতে দিলে |
| ফোন বন্ধ ছিল | My phone was off / dead | battery শেষ |
| ভিডিও কল করো | Let's video call | দেখা দরকার |
| হ্যালো? | Hello? | ফোন ধরলে প্রথম কথা |

```
[Phone rings]
Nila:   Hello?
Hasan:  Hey! I tried calling you earlier.
Nila:   সরি, phone silent এ ছিল।
Hasan:  কোনো সমস্যা নেই। কি করছিলে?
Nila:   তেমন কিছু না, বই পড়ছিলাম।
```

> [!note] "I tried calling" বনাম "I was calling"
> "I tried calling you" = কল করেছিলাম কিন্তু ধরলে না। "I was calling you" = কল করছিলাম (process)। প্রথমটা বেশি natural।

## 9. সাহায্য চাওয়া

সাহায্য চাইতে লজ্জা করবে না। সবাই একে অপরকে সাহায্য করে। চলো শিখি কীভাবে সুন্দর ভাবে সাহায্য চাইতে হয়।

| বাংলা | English | Note |
|--------|---------|------|
| একটা কাজ করবে? | Can you do me a favor? | ছোট কাজের জন্য |
| সাহায্য লাগবে | I need help / I need a hand | বড় কাজের জন্য |
| বুঝতে পারছি না | I don't understand / I don't get it | confuse হলে |
| আবার বলো | Say it again / Could you repeat that? | শুনতে পাইনি |
| দেখাও কীভাবে | Can you show me how? | প্র্যাকটিক্যাল জিনিস |
| কি মত? | What do you think? | opinion জানতে |
| আমার পক্ষে সম্ভব না | I can't help with that | politely না করা |
| একটু ধৈর্য ধরো | Bear with me | সময় দরকার |
| ব্যাখ্যা করবে? | Can you explain? | concept না বুঝলে |
| একটা মিনিট | Give me a second | ছোট সময় দরকার |

```
Rima:  Can you do me a favor?
Arif:  Sure, কি কাজ?
Rima:  এই assignment টা একটু দেখবে? বুঝতে পারছি না।
Arif:  দাও দেখি। Hmm, I don't get it either।
Rima:  তাহলে sir কে জিজ্ঞেস করা যাক।
```

> [!tip] "Favor" এর সঠিক ব্যবহার
> "Can you do me a favor?" হলো ছোট কাজ চাওয়ার নরমাল উপায়। বড় কাজের জন্য "Can you help me with...?" বেশি natural। "Do a favor" সবসময় ছোট কাজের জন্য ব্যবহার হয়।

## 10. Refusal ও Disagreement

না করতেও শিখতে হয়। সব কথায় হ্যাঁ বললে জীবন কঠিন হয়ে যায়। চলো শিখি কীভাবে politely না বলা যায়।

| বাংলা | English | Note |
|--------|---------|------|
| পারব না | I can't / I won't be able to | সরাসরি না |
| মন চায় না | I don't feel like it | mood নেই |
| এটা ঠিক না | That's not right / That's wrong | ভুল ধরা |
| একমত নই | I disagree / I don't agree | মত ভিন্ন |
| কোনোভাবেই না | No way / Not a chance | শক্ত না |
| এটা ঠিক না মনে হয় | I don't think so | সন্দেহ আছে |
| পরে দেখি | Maybe later / I'll pass for now | polite refusal |
| ভালো থাকবে | I'll pass | খুব polite না |
| এটা অসম্ভব | That's impossible | একদমই না |
| তা হবে না | That won't work | plan বাতিল |

```
Tamim: চলো আজকে party তে যাই!
Zara:  I don't feel like it। আমি tired।
Tamim: Please na! সবাই যাচ্ছে।
Zara: No way, আমি যাচ্ছি না।
Tamim: ঠিক আছে, maybe next time।
```

> [!important] "No" বলার শিষ্টাচার
> সবসময় নরমভাবে না করো। "No, I can't" এর পরিবর্তে "I don't think I can" বা "Maybe next time" বললে সম্পর্ক ভালো থাকে। Bangladeshi culture এ সরাসরি না করা খারাপ ধরা হয় — same thing ইংরেজিতেও।

## মনে রাখার কৌশল

> [!tip] ৫টি Golden Rule
> 1. **মুখে বলো** — শুধু চোখে পড়লে হবে না
> 2. **Context মনে রাখো** — কখন কোন বাক্য বলবে, সেটা ভাবো
> 3. **Response প্র্যাকটিস করো** — প্রতিটা বাক্যের reply কী হতে পারে, সেটা ভাবো
> 4. **Real conversation এ ব্যবহার করো** — বন্ধুদের সাথে, কাজে, যেখানেই পারো
> 5. **ভুল করতে ভয় পেও না** — ভুল না করলে শেখা হবে না

> [!example] একদিনের প্র্যাকটিস প্ল্যান
> - সকালে উঠে mirror এর সামনে "Good morning!" বলো
> - বন্ধুকে WhatsApp এ ইংরেজিতে একটা মেসেজ দাও
> - দুপুরে খাওয়ার সময় "It tastes great!" বলো
> - বিকেলে কাউকে "What's up?" দিয়ে কথা শুরু করো
> - রাতে "I'm tired, gotta sleep" লিখে ঘুমাতে যাও

- Greeting থেকে শুরু করে Refusal পর্যন্ত
- প্রতিটা বাক্যের note — কখন, কীভাবে বলবে
- Mini-dialogue — দুজনের কথা বলার pattern
- Pronunciation আর usage tips

মনে রাখবে — ইংরেজি শেখার সবচেয়ে বড় obstacle হলো লজ্জা। লজ্জা ছাড়ো, ভুল করো, শেখো। আজ থেকেই একটা বাক্য মুখে বলো। দেখবে এক সপ্তাহে অনেক এগিয়ে গেছো!

পরের চ্যাপ্টারে আমরা **Phrasal Verbs** শিখবো — get up, look for, take off — এই ধরনের ৫০+ verb phrase। সেগুলো জানা থাকলে কথা বলা আরও সহজ হয়ে যাবে।
