## 🟢 পর্ব ১: বেসিক কনসেপ্ট (The Core Theory)

### ১. Character Frequency (অ্যারে ম্যাপিং)
একটি স্ট্রিংয়ে কোন অক্ষরটি কতবার আছে তা $O(1)$ সময়ে বের করতে আমরা একটি ২৬ সাইজের অ্যারে ব্যবহার করি।

**ভিজ্যুয়ালাইজেশন:**
`c - 'a'` এর মানে কী?
কম্পিউটারে প্রতিটি অক্ষরের একটা ASCII মান থাকে (যেমন `a` = 97, `b` = 98)। 
যদি ক্যারেক্টার `c = 'c'` (ASCII 99) হয়, তবে `'c' - 'a'` মানে `99 - 97 = 2`। আমরা ঠিক 2-নম্বর ইনডেক্স (c এর জন্য) পেয়ে গেলাম!

```cpp
string s = "hello";
vector<int> freq(26, 0); 
for (char c : s) freq[c - 'a']++; 
```

### ২. 1D Prefix Sum (লুপ ছাড়াই রেঞ্জের যোগফল)
**ভিজ্যুয়ালাইজেশন (রিয়েল লাইফ অ্যানালজি):**
ধরো তুমি একটি ব্যাংকে প্রতিদিন টাকা জমা রাখো। 
দিন ১: 2 টাকা (মোট ব্যালেন্স: 2)
দিন ২: 4 টাকা (মোট ব্যালেন্স: 2+4 = 6)
দিন ৩: 1 টাকা (মোট ব্যালেন্স: 6+1 = 7)
দিন ৪: 5 টাকা (মোট ব্যালেন্স: 7+5 = 12)

এখন যদি তোমাকে কেউ জিজ্ঞেস করে, "দিন ২ থেকে দিন ৪ পর্যন্ত মোট কত টাকা জমিয়েছ?"
তুমি কি আবার ২, ৩, ৪ দিনের টাকা ধরে ধরে যোগ করবে? না! 
তুমি বলবে: "৪র্থ দিন শেষে আমার ব্যালেন্স ১২ টাকা। আর ১ম দিন শেষে ব্যালেন্স ছিল ২ টাকা। তাহলে ২য় থেকে ৪র্থ দিনের জমানো টাকা = ১২ - ২ = ১০ টাকা!" 

> **সূত্র:** $\text{Sum}(L, R) = \text{Balance}[R] - \text{Balance}[L-1]$

**স্ট্যান্ডার্ড কোড:**
```cpp
// 1-based indexing এর জন্য N+1 সাইজ
vector<long long> a(n + 1), pref(n + 1, 0); 

// O(N) সময়ে প্রিফিক্স সাম অ্যারে বা ব্যাংক ব্যালেন্স তৈরি
for (int i = 1; i <= n; i++) {
    cin >> a[i];
    pref[i] = pref[i - 1] + a[i]; 
}

// O(1) সময়ে Q টা কুয়েরির উত্তর দেওয়া
long long sum = pref[R] - pref[L - 1]; 
```

## 🔴 পর্ব ২: কনটেস্ট অ্যাপ্লিকেশন (Unlock the Algorithm)

### 📊 প্রবলেম ১: Difference Array (নির্দিষ্ট রেঞ্জে একসাথে আপডেট)
Prefix sum এর ঠিক উল্টো হলো Difference Array।
**প্রবলেম:** তোমাকে বলা হলো $L$ থেকে $R$ পর্যন্ত সব এলিমেন্টের সাথে $X$ যোগ করতে হবে। লুপ চালিয়ে সবগুলোতে $X$ যোগ করতে গেলে $O(N)$ সময় লাগবে। 

**লজিক:**
আমরা একটা `diff` অ্যারে রাখব।
$L$-তম পজিশনে $+X$ করে দেব। (এর মানে হলো, $L$ এর পর থেকে সবার সাথে $X$ যোগ হয়ে গেল)
কিন্তু $R$ এর পর তো আর $X$ যোগ হওয়ার কথা না! তাই $(R+1)$-তম পজিশনে $-X$ করে দেব। (যেন ব্যালেন্স হয়ে যায়)।
সবশেষে এই `diff` অ্যারের উপর **Prefix sum** চালালেই অরিজিনাল আপডেটেড অ্যারে পেয়ে যাব! (এটি $O(1)$ এ রেঞ্জ আপডেট করতে সাহায্য করে)।

```cpp
vector<long long> diff(n + 2, 0);

// L থেকে R পর্যন্ত X যোগ করা
diff[L] += X;
diff[R + 1] -= X;

// কাজ শেষে Prefix sum চালানো
for(int i = 1; i <= n; i++) {
    diff[i] += diff[i - 1];
    // এখন diff[i] তেই আপডেটেড মান আছে!
}
```

### 🧩 প্রবলেম ২: We Got Two Strings Before GTA-6 (Summer-25 A)
**প্রবলেম প্যাটার্ন:** দুটি স্ট্রিংয়ের ক্যারেক্টার ফ্রিকোয়েন্সি মিলিয়ে কোনো নির্দিষ্ট শর্ত পূরণ করা যায় কিনা দেখা। 
**Thought Process:**
১. প্রথম স্ট্রিংয়ের ফ্রিকোয়েন্সি `freq1` অ্যারেতে নাও।
২. দ্বিতীয় স্ট্রিংয়ের ফ্রিকোয়েন্সি `freq2` অ্যারেতে নাও।
৩. তারপর 0 থেকে 25 (a to z) পর্যন্ত লুপ চালিয়ে চেক করো যে `freq1` এবং `freq2` এর মধ্যে কোনো সম্পর্ক (যেমন: একটা থেকে আরেকটা বানানো যায় কিনা) আছে কি না!

### 🗺️ প্রবলেম ৩: 2D Prefix Sum (সাব-ম্যাট্রিক্স যোগফল)
**প্রবলেম প্যাটার্ন:** $N \times M$ সাইজের একটি ম্যাট্রিক্স দেওয়া আছে। $Q$ টি কুয়েরিতে $(r_1, c_1)$ থেকে $(r_2, c_2)$ পর্যন্ত সাব-ম্যাট্রিক্সের যোগফল বের করতে হবে।

**Thought Process:**
১. 1D এর মতোই, এখানে `pref[i][j]` মানে $(1,1)$ থেকে $(i,j)$ পর্যন্ত পুরো বক্সের যোগফল।
২. **ইনক্লুশন-এক্সক্লুশন (Inclusion-Exclusion):** বড় বক্স থেকে বাম দিকের বক্স আর উপরের বক্স বাদ দাও, কিন্তু কর্নার বক্সটা দুইবার বাদ পড়ে গেছে, তাই একবার যোগ করে দাও।
৩. এভাবে $O(NM)$ প্রি-প্রসেসিং করলে প্রতিটি কুয়েরি $O(1)$ সময়ে পাওয়া যাবে!

```cpp
// প্রিফিক্স তৈরি (1-based indexing)
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= m; j++) {
        pref[i][j] = a[i][j] + pref[i-1][j] + pref[i][j-1] - pref[i-1][j-1];
    }
}

// কুয়েরির উত্তর O(1) এ
long long sum = pref[r2][c2] - pref[r1-1][c2] - pref[r2][c1-1] + pref[r1-1][c1-1];
```
