# Dynamic Programming (Preliminary Core)

ডাইনামিক প্রোগ্রামিং (DP) নামটা শুনলেই অনেকেই ভয় পায়! কিন্তু প্রিলিমিনারি কনটেস্টে আসা DP গুলো সাধারণত সাধারণ রিকার্সন (Recursion) এবং মেমোইজেশন (Memoization) দিয়েই সলভ করা যায়। 

---

## 🟢 পর্ব ১: বেসিক কনসেপ্ট (The Core Theory)

### ১. DP আসলে কী? (Fibonacci Analogy)
DP এর মূল কনসেপ্ট হলো—"যে কাজ একবার করেছ, সেটা দ্বিতীয়বার করো না, খাতায় লিখে রাখো!"

**ভিজ্যুয়ালাইজেশন:**
ফিবোনাচি সিরিজের নিয়ম হলো: $F(N) = F(N-1) + F(N-2)$।
তুমি যদি সাধারণ রিকার্সন দিয়ে $F(5)$ বের করো:
- $F(5)$ ডাকবে $F(4)$ এবং $F(3)$ কে।
- $F(4)$ ডাকবে $F(3)$ এবং $F(2)$ কে।
খেয়াল করো, $F(3)$ কিন্তু দুইবার ডাকা হচ্ছে! $N$ বড় হলে একই কাজ বারবার করতে গিয়ে কোড TLE খাবে। 

**সমাধান (Memoization):**
আমরা একটা `dp` অ্যারে রাখব। যখনই কোনো $F(X)$ এর মান বের করব, সেটা `dp[X]` এ সেভ করে রাখব। পরে কেউ আবার $F(X)$ চাইলে ক্যালকুলেট না করে সরাসরি `dp[X]` দিয়ে দেব!

**স্ট্যান্ডার্ড কোড (Top-Down DP):**
```cpp
vector<long long> dp(100, -1); // -1 মানে এখনো মান বের করিনি

long long fib(int n) {
    if (n <= 1) return n; // বেস কেস
    
    if (dp[n] != -1) return dp[n]; // খাতায় লেখা থাকলে সরাসরি দিয়ে দাও!
    
    // খাতায় লেখা না থাকলে ক্যালকুলেট করো এবং সেভ করো
    return dp[n] = fib(n - 1) + fib(n - 2); 
}
```

### ২. 0/1 Knapsack (চোরের থলি)
**ভিজ্যুয়ালাইজেশন:**
একজন চোর একটা বাড়িতে ঢুকেছে। তার থলিতে সর্বোচ্চ $W$ কেজি জিনিস ধরে। বাড়িতে অনেকগুলো জিনিস আছে, প্রতিটির একটি নির্দিষ্ট ওজন এবং দাম আছে। চোর কোন কোন জিনিস নিলে থলির ওজন $W$ পার হবে না, কিন্তু দাম সর্বোচ্চ হবে? 
প্রতিটি জিনিসের জন্য চোরের কাছে দুটি অপশন:
১. জিনিসটি থলিতে **নেবে** (Take)
২. জিনিসটি **নেবে না** (Skip)

```cpp
long long solve(int index, int capacity) {
    if (index == 0 || capacity == 0) return 0;
    if (dp[index][capacity] != -1) return dp[index][capacity];

    // অপশন ১: জিনিসটি নেব না
    long long skip = solve(index - 1, capacity);
    
    // অপশন ২: জিনিসটি নেব (যদি ব্যাগে জায়গা থাকে)
    long long take = 0;
    if (weight[index] <= capacity) {
        take = value[index] + solve(index - 1, capacity - weight[index]);
    }

    return dp[index][capacity] = max(take, skip);
}
```

## 🔴 পর্ব ২: কনটেস্ট অ্যাপ্লিকেশন (Unlock the Algorithm)

### 🎒 প্রবলেম ১: Mina and the Lost Receipt (Summer-25 A)
**প্রবলেম প্যাটার্ন:** মিনা কিছু জিনিস কিনেছিল, যার একটি লিস্ট দেওয়া আছে (ওজন/দাম)। সে রিসিট হারিয়ে ফেলেছে কিন্তু তার ব্যাগের সর্বোচ্চ ক্যাপাসিটি সে জানে। সে সর্বোচ্চ কত টাকার জিনিস কিনে থাকতে পারে?
**Thought Process:**
এটি সরাসরি 0/1 Knapsack এর একটি অ্যাপ্লিকেশন। আমাদের কাছে জিনিসের ওজন এবং দামের লিস্ট আছে, আর ব্যাগের ক্যাপাসিটি দেওয়া আছে। আমরা উপরের `take` এবং `skip` রিকার্সন লিখে `max(take, skip)` বের করলেই উত্তর পেয়ে যাব। 

### 🪙 প্রবলেম ২: Coin Change (সীমাহীন কয়েন)
**প্রবলেম:** তোমার কাছে ১, ২ এবং ৫ টাকার অনেকগুলো কয়েন আছে। তোমাকে $X$ টাকা বানাতে হবে। সর্বনিম্ন কয়টি কয়েন লাগবে?
**Thought Process:**
0/1 Knapsack এ একটি জিনিস একবারই নেওয়া যেত। কিন্তু এখানে তুমি ৫ টাকার কয়েন অনেকবার নিতে পারো!
তাই `take` অপশনে যখন তুমি ৫ টাকার কয়েন নেবে, তুমি `index - 1` এ যাবে না, বরং ওই একই ইনডেক্সে (`index`) আবার ডাকবে!

```cpp
long long solve_coin(int index, int amount) {
    if (amount == 0) return 0; // টাকা বানানো শেষ (0 কয়েন লাগবে)
    if (index == 0) return INF; // কয়েন শেষ কিন্তু টাকা বানানো হয়নি
    
    if (dp[index][amount] != -1) return dp[index][amount];

    long long skip = solve_coin(index - 1, amount);
    
    long long take = INF;
    if (coins[index] <= amount) {
        // এখানে index - 1 না দিয়ে index দেওয়া হয়েছে, কারণ একই কয়েন আবার নেওয়া যাবে!
        take = 1 + solve_coin(index, amount - coins[index]);
    }

    return dp[index][amount] = min(take, skip);
}
```

### 📈 প্রবলেম ৩: LIS (Longest Increasing Subsequence)
**প্রবলেম:** একটি অ্যারে দেওয়া আছে। সবচেয়ে বড় সেই সাব-সিকোয়েন্স (Subsequence) বের করো যেখানে সব উপাদান কঠোরভাবে বাড়ছে (Strictly Increasing)। **সাব-সিকোয়েন্স** মানে অ্যারের ক্রম বজায় রেখে কিছু উপাদান বেছে নেওয়া (পাশাপাশি হতেই হবে এমন না)।

**Thought Process ($O(N^2)$ DP):**
১. `dp[i]` = "$i$-তম উপাদানে শেষ হওয়া" সবচেয়ে বড় বাড়তি সাব-সিকোয়েন্সের দৈর্ঘ্য।
২. প্রতিটি $i$ এর জন্য পেছনে সব $j$ ($j < i$) দেখব — যদি `a[j] < a[i]` হয়, তবে `dp[i]` কে `dp[j] + 1` এর সাথে max নেব।
৩. উত্তর হলো `max(dp[i])` সব $i$ এর জন্য।

```cpp
int lis(vector<int>& a) {
    int n = a.size();
    vector<int> dp(n, 1); // প্রতিটা নিজে একটা সাব-সিকোয়েন্স
    
    for (int i = 1; i < n; i++) {
        for (int j = 0; j < i; j++) {
            if (a[j] < a[i]) {
                dp[i] = max(dp[i], dp[j] + 1);
            }
        }
    }
    return *max_element(dp.begin(), dp.end());
}
```

> **কনটেস্ট টিপস:** $N$ বড় হলে ($N \ge 10^5$) `lower_bound` দিয়ে $O(N \log N)$ ভার্সন আছে — সেটা advanced এ পড়বে। প্রিলিমিনারিতে $O(N^2)$ ই যথেষ্ট। **প্যাটার্ন:** "সবচেয়ে বড় বাড়তি/কমতি সাব-সিকোয়েন্স", "সবচেয়ে বেশি জিনিস স্ট্যাক করা" — সবই LIS এর ভ্যারিয়েশন।
