# Two Pointers & Sliding Window (Preliminary Core)

অনেক সময় আমরা প্রবলেম দেখে দুইটা নেস্টেড লুপ ($O(N^2)$) লিখে ফেলি, যা TLE দেয়। যদি আমরা অ্যারের দুই মাথায় বা পাশাপাশি দুইটা "পয়েন্টার" (index) বসিয়ে কাজ করি, তবে পুরো জিনিসটা মাত্র $O(N)$ এ নেমে আসে। 

---

## 🟢 পর্ব ১: বেসিক কনসেপ্ট (The Core Theory)

### ১. Two Pointers কী? (Target Sum)
**প্রবলেম:** একটি সর্টেড অ্যারে থেকে এমন দুটি সংখ্যা বের করো যাদের যোগফল $X$ এর সমান।
**ভুল মেথড:** নেস্টেড লুপ চালিয়ে সব পেয়ার চেক করা ($O(N^2)$)।
**ভিজ্যুয়ালাইজেশন (Two Pointers):**
অ্যারের একদম প্রথমে (ছোট সংখ্যা) একটা আঙুল (`left`) রাখো, আর একদম শেষে (বড় সংখ্যা) আরেকটা আঙুল (`right`) রাখো। 
১. যদি দুই আঙুলের যোগফল $X$ এর চেয়ে **বড়** হয়, তবে যোগফল কমানোর জন্য ডান দিকের আঙুলটা বামে সরাও (`right--`)।
২. যদি যোগফল $X$ এর চেয়ে **ছোট** হয়, তবে যোগফল বাড়ানোর জন্য বাম দিকের আঙুলটা ডানে সরাও (`left++`)।
৩. মিলে গেলে তো পেয়েই গেলে! ($O(N)$ সময়)।

```cpp
bool hasTargetSum(vector<int>& a, int X) {
    int left = 0, right = a.size() - 1;
    while (left < right) {
        int sum = a[left] + a[right];
        if (sum == X) return true;
        else if (sum < X) left++;
        else right--;
    }
    return false;
}
```

### ২. Sliding Window কী?
ধরো তোমাকে বলা হলো $K$ সাইজের পরপর এলিমেন্টগুলোর যোগফল বের করতে।
**ভিজ্যুয়ালাইজেশন (রিয়েল লাইফ অ্যানালজি):**
ধরো একটা লম্বা দেয়ালে ১০টা ছবি পাশাপাশি ঝোলানো আছে। তোমার কাছে একটা জানালার ফ্রেম (Window) আছে যার ভেতরে একসাথে ৩টি ছবি দেখা যায়। 
প্রথমে তুমি ফ্রেমটা রাখলে ১, ২, ৩ নম্বর ছবির উপর। 
এখন তুমি ফ্রেমটা এক ঘর ডানে সরালে। ফ্রেমের ভেতর এখন ২, ৩, ৪ নম্বর ছবি। 
লক্ষ্য করো, ফ্রেম সরানোর সময় কী ঘটল? **নতুন একটা ছবি (৪) ভেতরে ঢুকল, আর পুরোনো একটা ছবি (১) ফ্রেমের বাইরে চলে গেল।** 

```cpp
// প্রথম জানালা (0 থেকে k-1)
for (int i = 0; i < k; i++) current_window_sum += a[i];

// জানালার ফ্রেম ডানে সরানো
for (int i = k; i < n; i++) {
    // নতুনটা (i) যোগ হলো, পেছনেরটা (i-k) বাদ পড়ল
    current_window_sum += a[i] - a[i - k]; 
}
```

## 🔴 পর্ব ২: কনটেস্ট অ্যাপ্লিকেশন (Unlock the Algorithm)

### 🍬 প্রবলেম ১: Mystic Box of Infinite Glucose (DIU Spring-26 Prelim A)
**প্রবলেম:** একটি বাক্সে $N$ টি ক্যান্ডি আছে। Player 1 সবসময় বাক্স থেকে **সবচেয়ে বড়** ক্যান্ডিটা নেয় এবং Player 2 সবসময় **সবচেয়ে ছোট** ক্যান্ডিটা নেয়। কে কত গ্লুকোজ পাবে?

**Thought Process:**
১. প্রথমে ক্যান্ডিগুলোকে সর্ট করো। এখন সবচেয়ে ছোটটা শুরুতে এবং বড়টা শেষে আছে।
২. Two Pointers সেট করো: `left = 0`, `right = N - 1`।
৩. Player 1 এর টার্নে `right` এর ক্যান্ডিটা দিয়ে দাও এবং `right--` করো।
৪. Player 2 এর টার্নে `left` এর ক্যান্ডিটা দিয়ে দাও এবং `left++` করো।

```cpp
void solve_candy() {
    // ... input ...
    sort(candies.begin(), candies.end());

    int left = 0, right = n - 1;
    long long p1 = 0, p2 = 0;
    bool turn = true; // true = P1, false = P2

    while (left <= right) {
        if (turn) {
            p1 += candies[right]; right--; 
        } else {
            p2 += candies[left];  left++; 
        }
        turn = !turn; 
    }
    cout << p1 << " " << p2 << "\n";
}
```

### 🪟 প্রবলেম ২: Max Sum Subarray of Size K
**প্রবলেম প্যাটার্ন:** একটি অ্যারে থেকে $K$ সাইজের এমন একটি সাব-অ্যারে বের করো যার যোগফল সর্বোচ্চ। 
**লজিক:** আমরা স্লাইডিং উইন্ডো ব্যবহার করব। প্রথমে প্রথম $K$ টি উপাদানের উইন্ডোর হিসাব করব। তারপর উইন্ডো এক ঘর করে সরাব। নতুন ক্যারেক্টার ঢুকলে তার ভ্যালু যোগ করব, আর পুরোনো ক্যারেক্টার বের হলে তার ভ্যালু বিয়োগ করব। প্রতি ধাপে `max_sum` আপডেট করব।

### 🔤 প্রবলেম ৩: Longest Substring Without Repeating Characters
**প্রবলেম:** একটি স্ট্রিং দেওয়া আছে। সবচেয়ে বড় সেই সাব-স্ট্রিং বের করো যেখানে কোনো ক্যারেক্টার দুইবার নেই।

**Thought Process (Variable Sliding Window):**
১. আগের `K` সাইজের উইন্ডো ছিল **fixed**। এখন উইন্ডোর সাইজ **variable** — যতক্ষণ শর্ত মানছে, তত বড় হবে।
২. দুইটা পয়েন্টার `left` আর `right` রাখব। `right` কে সামনে বাড়াব একটা একটা করে ক্যারেক্টার ঢুকাব উইন্ডোতে।
৩. যদি নতুন ক্যারেক্টার আগে থেকে থাকে (ডুপ্লিকেট), তবে `left` কে সামনে সরাব যতক্ষণ না ডুপ্লিকেট বেরিয়ে যায়।
৪. প্রতি স্টেপে উইন্ডোর সাইজ `right - left + 1` দিয়ে সর্বোচ্চ আপডেট করব।

```cpp
int longestUniqueSubstring(string& s) {
    unordered_map<char, int> last_seen; // ক্যারেক্টার -> শেষ কোথায় দেখেছি
    int left = 0, max_len = 0;
    
    for (int right = 0; right < s.size(); right++) {
        // যদি ক্যারেক্টারটি আগে দেখা থাকে এবং সেটা উইন্ডোর ভেতরে
        if (last_seen.count(s[right]) && last_seen[s[right]] >= left) {
            left = last_seen[s[right]] + 1; // left কে ডুপ্লিকেটের পরের ঘরে নিয়ে যাও
        }
        last_seen[s[right]] = right;
        max_len = max(max_len, right - left + 1);
    }
    return max_len;
}
```

> **প্যাটার্ন চিনবে যেভাবে:** "Longest/Shortest subarray with condition" — এই টাইপের প্রশ্নে variable sliding window ব্যবহার করবে।
