# Graphs & 2D Grid Traversal (Preliminary Core)

কনটেস্টে 2D Grid বা ম্যাট্রিক্সের প্রবলেম খুব কমন। যেমন—"একটা গোলকধাঁধা (Maze) দেওয়া আছে, তোমাকে (0,0) থেকে (N,N) এ যেতে হবে, পথে দেয়াল (#) আছে।"

## 🟢 পর্ব ১: বেসিক কনসেপ্ট (The Core Theory)

### ১. Breadth-First Search (BFS) কী?
**ভিজ্যুয়ালাইজেশন (রিয়েল লাইফ অ্যানালজি):**
ধরো এক ফোঁটা পানি গ্রিডের `(0, 0)` সেলে ফেললে। পানি কিন্তু একসাথে সব দিকে (ডানে, বামে, নিচে) সমানভাবে ছড়াবে। 
১ সেকেন্ড পর পানি ১ ঘর দূরত্বের সব জায়গায় পৌঁছাবে। ২ সেকেন্ড পর ২ ঘর দূরত্বের সব জায়গায় পৌঁছাবে।
এভাবেই পানি ছড়াতে ছড়াতে যখন টার্গেট সেলে পৌঁছাবে, সেটাই হবে সবচেয়ে কম সময় বা Shortest Path! 
কম্পিউটার সায়েন্সে এই "পানির মতো ছড়ানো" কেই **BFS** বলে। এটি সবসময় Shortest Path দেয় (যদি সব এজের ওজন সমান হয়)।

**স্ট্যান্ডার্ড কোড (Queue এর ব্যবহার):**
পানি প্রথমে কোথায় ছিল? `(0, 0)` তে। একে একটা লাইনে (Queue) দাঁড় করাও।
এবার লাইন থেকে একজনকে বের করো। দেখো তার আশেপাশে কোথায় যাওয়া যায়। যেখানে যাওয়া যায়, তাদের দূরত্ব ১ বাড়িয়ে দিয়ে আবার লাইনের পেছনে দাঁড় করিয়ে দাও।

```cpp
int dx[] = {-1, 1, 0, 0}; // 4-Directional Movement
int dy[] = {0, 0, -1, 1};

void bfs_grid(int startX, int startY) {
    queue<pair<int, int>> q; 
    dist.assign(R, vector<int>(C, -1)); // দূরত্ব -1 মানে এখনো যাইনি

    q.push({startX, startY}); 
    dist[startX][startY] = 0; 

    while (!q.empty()) {
        auto [x, y] = q.front(); 
        q.pop(); 

        for (int i = 0; i < 4; i++) {
            int nx = x + dx[i], ny = y + dy[i];
            // গ্রিডের ভেতরে আছে এবং আগে যাইনি
            if (nx >= 0 && nx < R && ny >= 0 && ny < C && dist[nx][ny] == -1) { 
                dist[nx][ny] = dist[x][y] + 1; 
                q.push({nx, ny}); 
            }
        }
    }
}
```

### ২. Depth-First Search (DFS) কী?
DFS মানে এক রাস্তা ধরে যতক্ষণ পারা যায় সামনে যাওয়া। 
**ভিজ্যুয়ালাইজেশন:** দ্বীপ গণনা (Connected Components)। গ্রিডে লুপ চালাবে। যখনই মাটি পাবে, তুমি বুঝবে একটা দ্বীপ পেয়েছো (Count++)। এরপর ওই দ্বীপের সাথে লাগানো সব মাটিকে DFS দিয়ে পানিতে ডুবিয়ে দেবে, যেন ওই একই দ্বীপ দুইবার গোনা না হয়!

## 🔴 পর্ব ২: কনটেস্ট অ্যাপ্লিকেশন (Unlock the Algorithm)

### 🚇 প্রবলেম ১: Dhaka Metro: Escape the Blackout (Spring-26 B)
**প্রবলেম প্যাটার্ন:** ঢাকা মেট্রোর ম্যাপ দেওয়া আছে। কিছু স্টেশনে কারেন্ট নেই। তোমাকে শুরু থেকে শেষ স্টেশনে যেতে হবে সবচেয়ে কম সময়ে।
**Thought Process:**
যেহেতু "সবচেয়ে কম সময়" (Shortest Path) বের করতে হবে এবং গ্রিড/ম্যাপ দেওয়া আছে, আমরা সরাসরি BFS চালাব। 
শর্ত হিসেবে শুধু দেখব যে পরের স্টেশনে কারেন্ট আছে কিনা (যেমন গ্রিডের দেয়ালে ধাক্কা খাওয়ার শর্ত `grid[nx][ny] != '#'` এর মতো)।

### 🏝️ প্রবলেম ২: Floral Festival (Summer-25 A)
**প্রবলেম প্যাটার্ন:** একটি বাগানে বিভিন্ন রঙের ফুল ফুটেছে। একই রঙের ফুল পাশাপাশি থাকলে তারা একটি ক্লাস্টার তৈরি করে। সবচেয়ে বড় ক্লাস্টারের সাইজ কত?
**Thought Process:**
১. এটি মূলত "Max Connected Component" বা সবচেয়ে বড় দ্বীপ খোঁজার প্রবলেম।
২. আমরা গ্রিডের প্রতিটি সেলে লুপ চালাব। যদি কোনো সেল ভিজিট করা না থাকে, তবে সেখান থেকে DFS শুরু করব।
৩. DFS চালানোর সময় আমরা কাউন্ট রাখব যে কতগুলো সেল ভিজিট করলাম। 
৪. DFS যে কাউন্ট রিটার্ন করবে, সেটা `max_size` এর সাথে তুলনা করে আপডেট করব।

```cpp
int dfs_flower(int r, int c, char color) {
    visited[r][c] = true;
    int size = 1;

    for (int i = 0; i < 4; i++) {
        int nr = r + dx[i], nc = c + dy[i];
        if (nr >= 0 && nr < R && nc >= 0 && nc < C) {
            if (!visited[nr][nc] && grid[nr][nc] == color) {
                size += dfs_flower(nr, nc, color); // সাইজ যোগ করছি
            }
        }
    }
    return size;
}
```
