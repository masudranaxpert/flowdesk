# Trees, DFS & LCA / Binary Lifting (Preliminary Core)

ট্রি (Tree) মানে হলো এমন একটা গ্রাফ যেখানে কোনো লুপ বা সাইকেল নেই। কনটেস্টের প্রিলিমিনারিতে ট্রি থেকে সাধারণত DFS এবং LCA (Lowest Common Ancestor) এর প্রবলেম আসে। 

---

## 🟢 পর্ব ১: বেসিক কনসেপ্ট (The Core Theory)

### ১. Depth-First Search (DFS)
DFS হলো একটা গাছের একদম শেকড় থেকে শুরু করে একটা ডাল ধরে একদম শেষ পাতা পর্যন্ত যাওয়ার প্রক্রিয়া। 
**ভিজ্যুয়ালাইজেশন:** তুমি একটা গোলকধাঁধায় ঢুকেছ। তুমি একটা রাস্তা ধরে হাঁটতে থাকলে, যতক্ষণ না দেয়ালে ধাক্কা খাও। দেয়ালে ধাক্কা খেলে একটু পিছনে এসে অন্য রাস্তা ধরলে। 

```cpp
vector<int> adj[100005]; // ট্রি এর স্ট্রাকচার

void dfs(int u, int parent) {
    // u হলো বর্তমান নোড, parent হলো যেখান থেকে এসেছি
    cout << "বর্তমানে আছি: " << u << "\n";
    
    for (int v : adj[u]) {
        if (v != parent) { // যেখান থেকে এসেছি সেখানে ফেরত যাব না
            dfs(v, u);
        }
    }
}
```

### ২. Lowest Common Ancestor (LCA) ও Binary Lifting
**ভিজ্যুয়ালাইজেশন:** তুমি আর তোমার বন্ধু দুইটা আলাদা ডালে (Node u এবং v) বসে আছো। তোমরা দুজন যদি নিচের দিকে (রুটের দিকে) নামতে থাকো, তবে প্রথম যে ডালটায় তোমাদের দেখা হবে, সেটাই হলো **LCA**।
**ম্যাজিক জাম্প:** একটা একটা করে উপরে উঠলে অনেক সময় লাগবে। আমরা যদি $2^0, 2^1, 2^2, 2^3 \dots$ (১, ২, ৪, ৮) স্টেপে লাফ দিতে পারি? ৫ স্টেপ উপরে যেতে হলে আমরা প্রথমে ৪ স্টেপের একটা লাফ দেব, তারপর ১ স্টেপের একটা লাফ দেব ($4+1=5$)! একেই বলে Binary Lifting.

```cpp
// 2^i স্টেপ উপরে কে আছে তা হিসাব করা
for (int i = 1; i < LOGN; i++) {
    up[u][i] = up[ up[u][i - 1] ][i - 1]; 
}
```

## 🔴 পর্ব ২: কনটেস্ট অ্যাপ্লিকেশন (Unlock the Algorithm)

### 🌲 প্রবলেম ১: Easy Path (DIU Fall-23 Final)
**প্রবলেম:** রুট থেকে যেকোনো নোড পর্যন্ত একটা রাস্তা তৈরি করো যেন রাস্তার সব কস্ট $X$ দ্বারা বিভাজ্য হয়। তুমি চাইলে স্পেশাল পাওয়ার দিয়ে যেকোনো একটি এজকে $X$ দ্বারা বিভাজ্য বানাতে পারো। সবচেয়ে বড় রাস্তাটি কত?

**Thought Process:**
১. আমাকে রুট থেকে নিচের দিকে যেতে হবে (DFS)।
২. রাস্তায় যাওয়ার সময় কস্ট চেক করব। বিভাজ্য না হলে সেটি একটি Bad Edge।
৩. স্পেশাল পাওয়ার একবারই ব্যবহার করা যাবে, তাই রাস্তায় সর্বোচ্চ ১টি Bad Edge থাকতে পারবে।
৪. যদি ২টা Bad Edge পাই, আমি থেমে যাব। 

```cpp
void dfs_easy_path(int u, int parent, int depth, int bad_edges) {
    if (bad_edges > 1) return; // স্পেশাল পাওয়ার শেষ! 
    
    if (depth > max_depth) { // সবচেয়ে বড় রাস্তা আপডেট করা
        max_depth = depth;
        best_node = u;
    }
    
    for (auto edge : adj[u]) {
        int v = edge.to;
        if (v != parent) {
            int new_bad = bad_edges + (edge.cost % X != 0 ? 1 : 0);
            dfs_easy_path(v, u, depth + 1, new_bad);
        }
    }
}
```

### 🧬 প্রবলেম ২: Pokémon Path Quest (DIU Spring-25 Prelim A)
**প্রবলেম:** $u$ এবং $v$ দুটি নোড। এদের মধ্যে যাওয়ার সিম্পল পাথে $k$-তম নোডটি কে?
**Thought Process:**
১. প্রথমে $u$ এবং $v$ এর মধ্যে LCA বের করতে হবে।
২. তারপর দেখতে হবে $k$-তম নোডটি কি $u$ থেকে LCA এর রাস্তায় আছে, নাকি LCA থেকে $v$ এর রাস্তায় আছে?
৩. যেখানেই থাকুক, আমরা **Binary Lifting** ব্যবহার করে $O(\log N)$ সময়ে সেই নোডটিতে লাফ দিয়ে পৌঁছে যাব!

### 🌳 প্রবলেম ৩: Subtree Size (Tree DP এর ভিত্তি)
**প্রবলেম প্যাটার্ন:** একটি রুটেড ট্রি (Rooted Tree) দেওয়া আছে। প্রতিটি নোডের সাব-ট্রিতে (Subtree) কতগুলো নোড আছে তা বের করো।

**Thought Process (DFS Return Value):**
১. যেকোনো নোড $u$ এর সাব-ট্রি সাইজ = $1$ (নিজে) + তার সব চিলড্রেনের সাব-ট্রি সাইজের যোগফল।
২. এটাই **Tree DP** এর মূল আইডিয়া — নিচ থেকে উপরে (bottom-up) হিসাব করা।
৩. DFS চালানোর সময় রিকার্সিভ কল থেকে ভ্যালু রিটার্ন করে নাও, তারপর সেটা প্যারেন্টে যোগ করো।

```cpp
vector<int> subtree_size(100005, 0);

int dfs_size(int u, int parent) {
    int size = 1; // নিজেকে গোনা
    for (int v : adj[u]) {
        if (v != parent) {
            size += dfs_size(v, u); // চিলড্রেনের সাব-ট্রি সাইজ যোগ
        }
    }
    subtree_size[u] = size;
    return size;
}
```

> **কনটেস্ট প্যাটার্ন:** সাব-ট্রি সাইজ জানা থাকলে আরও অনেক প্রবলেম সলভ করা যায় — যেমন "কোনো এজ কাটলে ট্রি কি দুই সমান ভাগে ভাঙে?" বা "সেন্ট্রয়েড (Centroid) কোথায়?"। প্যাটার্নটা মাথায় রাখো: **DFS থেকে ভ্যালু রিটার্ন = Tree DP**।
